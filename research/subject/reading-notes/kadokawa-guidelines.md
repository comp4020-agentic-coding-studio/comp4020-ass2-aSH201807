## 1. Publication header

- Published by the official Call of Cthulhu TRPG note account (KADOKAWA) on December 16, 2024.

## 2. Introductory note

- Writers are asked to keep a broad readership in mind and use clear, grammatically correct Japanese.
- Recommends referencing scenarios already published in "New Call of Cthulhu TRPG Scenario Collection: Bibliotheque 13" as examples of the expected style.

## 3. Basic Format Rules

- Lines are limited to 26 characters per line.
- Maximum total length: 800 lines.
- Major headings require one blank line both above and below.
- Minor (other) headings require one blank line above only.
- Both of these blank-line spacing rules count toward the 800-line total.

## 4. Scenario Sections and Content

### 4.1 Title and Overview
- A separate summary of roughly 400 characters, covering the flow from introduction to conclusion, written apart from the main scenario text.
- This overview does not count toward the 800-line limit.

### 4.2 Lead (~5 lines)
- Marks the start of the main scenario text proper.
- Should read like a Keeper's own recruitment post — conveying the story's atmosphere and the investigators' role.
- If there's a specific practical message needed (e.g. whether combat is avoidable or unavoidable), it should be stated here.
- Example 1 given: a modern rural Japanese town in summer; investigators hear a prophecy of disaster from a mysterious figure; combat is possible depending on circumstances.
- Example 2 given: modern America in summer; investigators witness a disturbing ritual in a village and must rely on their own wit/courage to save someone important, with no outside help available.

### 4.3 Section 1 — Introduction (はじめに)
- Should state required rulebooks/sourcebooks.
- Should state expected number of players.
- Should state estimated play time.
- Should state suitable occupations/skills for the scenario.
- Should state the intended tone of the scenario where relevant, cross-referencing the core rulebook's "Deciding the Tone" section (p.181).
- Worked example given: a scenario compatible with the core rulebook plus the "Creating and Playing Younger Investigators" rules from Cthulhu 2020; designed for 3–4 freshly created investigators; ~4 hours excluding character creation; suggests a somewhat comedic tone; encourages proactive investigator behavior; notes combat-capable investigators and a college-student investigator would help smooth the introduction; notes high Navigate skill could also be useful.

### 4.4 Section 2 — Information for the Keeper (キーパー向け情報)
- Contains the truth known only to the Keeper.
- Purpose stated explicitly: let readers grasp the scenario's full picture early, to deepen understanding of the rest of the text.

### 4.5 Section 3 — Information for Players (プレイヤー向け情報)
- Optional section — only included if needed.
- Used when there's substantial background information investigators/players should know at the outset.

### 4.6 Section 4 — Main NPCs (主なNPC)
- Describes major NPCs: background, personality, connection to the scenario.
- Stats and skills should be compiled here if necessary.
- For important NPCs, recommends brief notes on "physical description," "characteristics," and "roleplaying hooks."
- Full worked example NPC stat block given — "Betty Slocomb (18), a controlled flapper":
  - Characteristics: STR 35, CON 50, SIZ 45, DEX 50, INT 50, APP 75, POW 35, EDU 45.
  - Sanity 32, HP 9, Damage Bonus −1, Build −1, Move 8, Magic Points 7.
  - Combat: Close Combat (Brawl) 25% (12/5), damage 1D3+DB; Dodge 25% (12/5).
  - Skills: Drive Auto 50%, Art/Craft (Dance) 40%, Library Use 60%, Charm 60%.
  - Spells: Dominate, Wither Limb, and a warding spell (rendered here as "Nyarlathotep's Barrier"-type ward; exact spell name uncertain due to the translation layer — flagged rather than guessed at).

### 4.7 Section 5 — Scenario Introduction/Hook (シナリオの導入)
- Describes how investigators become involved in the unfolding events (encountering something strange, receiving a request to investigate, etc.).
- Includes advice on motivating the investigators to engage.

### 4.8 Structuring the body (note between sections)
- States that sections after the Introduction should be divided by major incident, scene, or location, to improve clarity — implies no single fixed template for the "middle" of a scenario, only for its bookends.

### 4.9 Conclusion (結末)
- The final section.
- Should include advice on how to wrap up the incident.
- Should include any epilogue material.
- Should include rewards, such as Sanity point gains for investigators.

### 4.10 Other (その他) — notation conventions
- All brackets specified are full-width characters.
- Skill names and Sanity rolls: 〈 〉
- Formulas/calculations: ［ ］
- Spell-related terms: 《 》
- Tome/book/film titles: 『 』
- Proper nouns (personal names, place names): give the reading/pronunciation the first time they appear — example given: "Yamada Tarō (やまだたろう)."
