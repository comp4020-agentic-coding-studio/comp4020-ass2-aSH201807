# Sources — subject matter (CoC scenario design)

Course topic (locked in): **how to write a Call of Cthulhu TRPG scenario from
scratch** — not "how to play CoC", but how a Keeper turns a vague horror idea
into a runnable investigation scenario.

Everything below was surfaced in one ChatGPT-assisted search pass. **All 9
have now been individually verified** (2026-09-13: link resolves, author/venue
real, content matches the description — see per-row notes for corrections).
Verified ≠ read-and-synthesized yet — that's still `notes.md`'s job.
