This studio applies two different ways of categorising the same clue web —
by what it does for the player (guiding them to the next scene, or
revealing what the truth actually means) and how it's delivered
(literature, a conversation, or physical trace), alongside a second lens
built around redundancy (core, supporting, and advantage clues). Neither
model is "more correct" — this week is about using both on your own draft
and seeing what each one catches that the other doesn't.

## Before the session

Bring your scene map from week 5. You'll be marking it up directly, so
leave room on the page (or a column, if it's a spreadsheet).

## In the session

Tag every clue in every scene against both taxonomies. Then check
redundancy specifically: for each node that's load-bearing (removing it
would break the whole chain), is there a second way to reach the same
information? If not, that's this week's homework.

## Afterwards

Fix any node that has exactly one path to a critical piece of information.
Weeks 7 and 8 build puzzles and checks on top of this map, so a gap here
becomes a real stuck point at the table later.
